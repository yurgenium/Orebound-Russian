- Deep Strata — Глубинные пласты; Deepstone — Глубинный камень
- Ancient Strata — Древние пласты; Ancient Rock — Древняя порода
- Abyssal Strata — Пласты бездны; Abyssal Stone — Камень бездны
- Corebound (зона) — Приядерье; Corebound Strata — Приядерные пласты; Corestone — Камень ядра
- World Core — Ядро мира; World Core Expanse — Просторы Ядра мира; Worldstone — Мировой камень
- geology ring/zone — геологическое кольцо/зона; strata — пласты
